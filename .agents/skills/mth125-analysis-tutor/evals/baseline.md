# Baseline: no MTH125 skill

Scenario combined time pressure, incomplete notes, permission to consult the textbook, and a request to skip directly to exercises.

Observed failures before authoring the skill:

- It skipped a separate Example/AI-review stage: “未另设例题环节，以符合‘时间很紧、直接挑题’的要求。”
- It did not create durable learning state: “未建立笔记锚点或错误清单，也未写入文件。”
- It produced proofs, but did not report a Topic-specific checklist followed by the general proof audit required by the design.

The skill therefore makes the schedule/Example gate, persistent anchors, Topic error registry, and two-pass proof audit explicit requirements that time pressure cannot silently remove.
